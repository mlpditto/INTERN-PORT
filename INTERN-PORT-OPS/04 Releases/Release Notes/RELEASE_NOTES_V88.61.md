# Intern Admin Portal - Release Notes V88.61 🚀

## Overview: The Logic-Color Harmonic Overhaul

This release focuses on **Cognitive Ergonomics** and **Strategic UI Organization**. By implementing a strict "Red vs Green" logic partition, we have reduced visual noise and created an intuitive hierarchy for administrative actions.

---

### 🎨 Visual Identity Reorganization

#### 🔴 THE RED GROUP: Core Structure & Logic
*All elements that define the **fundamental structure** of the quiz and questions.*

*   **Dashboard MODE Selector:** Updated to a clean, blue-primary glass-tab design.
*   **Editor TYPE Tabs:** Categorized "Choice, Short, Order, Card" as top-level structural decisions.
*   **Unified Identity:** Core logic actions now share identical blue button styling, helping administrators differentiate "what it is" from "what it can do."

#### 🟢 THE GREEN GROUP: Intelligence & AI Tools
*All elements that represent **Intelligence layers** and content enhancement.*

*   **Global Toolkit:** Unified "AI Analyze" and "PDF Import" under a professional **Purple/Amethyst** theme.
*   **Integrated AI Hub:** Harmonized the Question-specific AI toggles (Models/Languages) with the global purple intelligence identity.
*   **Magic Enhance:** Upgraded the "Magic" button to a signature gradient purple to signify advanced AI operations.

---

### 🛠️ Hardware & UX Standardizations

*   **Uniform Action Grid:** All utility actions (Copy, Clone, Delete) are now fixed at **38px with a 14px radius** for a premium, tactile feel.
*   **Timer LEGEND:** Added explicit **"SEC"** unit labels to solve ambiguity in time-per-question settings.
*   **Professional API Settings:** Migrated key management to a dedicated **Primary-Colored Gear Icon** for cleaner UI and better accessibility.
*   **Stability Enhancements:** Locked the Participants Modal at **z-index: 20000** for consistent overlay behavior.
