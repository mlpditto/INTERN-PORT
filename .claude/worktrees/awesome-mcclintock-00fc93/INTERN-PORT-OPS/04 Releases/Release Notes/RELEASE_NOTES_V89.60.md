# Release Notes (V89.60) - Lean UI & AI Grading Master Update

## 🖼 Laugh Tale Refactor (Lean UI)
- **Compact Header:** Refactored the Laugh Tale section to use a horizontal flex header, saving over 50% of vertical space.
- **Unified Intelligence Bar:** Merged AI model selection and action buttons into a sleek, right-aligned toolbar.
- **Premium Aesthetics:** Updated typography (Cormorant Garamond) and visual hierarchy for a high-end dashboard feel.

## 📝 Enhanced Short Answer Mode
- **Refined User Experience:** Short Answer questions in the LIFF app now use a single, focused textarea instead of the multiple-box UI.
- **Integrated AI Grading:** Added a "🤖 AI Evaluate" button in the Admin review portal. AI now analyzes student responses against set guidelines and suggests scoring.
- **Guideline Support:** Admins can now set "Keywords/Guidelines" in the editor for the AI to use during the evaluation process.

## 🛠 Quiz Editor Usability
- **Visibility Fix:** Corrected low-contrast text in quiz options (Dark text on Light background).
- **Initialization Fix:** New questions now default to *no correct answer selected*, reducing bias and ensuring deliberate grading configuration.
