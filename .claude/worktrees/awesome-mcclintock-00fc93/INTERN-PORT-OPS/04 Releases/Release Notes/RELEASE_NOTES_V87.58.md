# Release Notes: Admin Portal V87.58

## 🚀 Major Update: AI Evolution & GPT-5.4 Integration
This version introduces a complete overhaul of the AI model lineup and a redesigned "Pastel" themed control center for optimized productivity.

### 🤖 New AI Frontier: GPT-5.4 Series
We've replaced the legacy GPT-4o with the cutting-edge **GPT-5.4** family to provide smarter, faster, and more cost-effective intelligence across the platform.
-   **GPT-5.4 (Standard)**: Enhanced reasoning and deep analysis for research and content creation.
-   **GPT-5.4 mini**: High-intelligence, low-latency. Best for daily reviews and quick summaries.
-   **GPT-5.4 nano**: Hyper-optimized for instantaneous responses and low-resource tasks.

### 🎨 Premium "Pastel" UI Design
The AI Digital Hub and Quiz Toolkit have been restyled with a modern, high-contrast pastel aesthetic.
-   **Consolidated AI Header**: Unified Usage Meter, API Settings, and Model selection into a single, cohesive dashboard component.
-   **Improved Readability**: Sharp typography and clean color-coded badges make it easier to distinguish between model types and usage levels.
-   **Micro-interactions**: Added smooth transitions and hover effects to all AI action buttons.

### 🛠️ Backend Architecture (V87.58)
-   **Proxy Optimization**: Updated the Firebase Cloud Function (`callAIProxy`) to support direct routing for the GPT-5.4 series.
-   **Smart Mapping**: `callUniversalAI` now intelligently maps model strings and optimizes token limits (up to 4096 tokens) for the new frontier models.
