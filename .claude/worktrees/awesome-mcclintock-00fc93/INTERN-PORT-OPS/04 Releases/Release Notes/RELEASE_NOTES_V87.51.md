# Release Notes: Admin Portal V87.51

## 🚀 New Feature: PDF-to-Quiz Generation (NotebookLM-like)
The Admin Portal now supports generating high-quality quizzes directly from Knowledge Base sources (PDF, Text, Images).

### Key Highlights
- **Direct KB Selection**: Choose any indexed document as the "Source of Truth" for your quiz.
- **Adjustable Question Counts**: Generate 5 to 20 questions in a single pass.
- **Grounded AI Generation**: Leverages Gemini 1.5 (Pro or Flash) to extract structured data precisely from the document content.
- **Zero-Refresh Workflow**: New questions are injected directly into the Quiz Editor UI and auto-saved as a draft.

### Integration
Accessible via the **⚡ Generate from PDF** button in the Quiz Toolbar.
