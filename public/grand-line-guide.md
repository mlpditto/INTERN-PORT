## 1. 🖼 ภาพ

**ที่ไหน:** 🏴 Miss Goldenweek

1. เลือกสไตล์ใน **Visual Style Collection** ด้านซ้าย (Pirate Crew Life, Jolly Roger Vector, 3D Devil Fruit, Grand Line Map, Oda Manga Style, Wano Arc Anime) สไตล์จะถูกใส่ในทุก prompt
2. บรรยายภาพในช่อง **🪄 Vision** สูตรข้างหัวข้อคือ *Context + Goal + Source + Expectations* พิมพ์ไทยได้
3. บน toolbar ใต้ช่อง ✒ คือ **โมเดล enhancer** (แปลงข้อความเป็น prompt อังกฤษที่มีโครงสร้าง แท็บโลโก้เลือกเจ้า ชิปเลือกรุ่น) แล้วเลือก **engine**: **Nano Banana 2.1** (Google ถูกสุด เหมาะกับไดอะแกรม/อินโฟกราฟิก) หรือ **Image 2** (OpenAI เก่งตัวหนังสือ)
4. กด **✨ Create** ระบบจะโชว์ prompt อังกฤษให้แก้หรือยืนยันก่อน แล้ว engine ค่อยวาด
5. ภาพขึ้นในการ์ดพรีวิว จากนั้นดาวน์โหลด ส่งเข้า Codex หรือวาดใหม่ด้วยอีก engine ได้

> ภาพเก่าอยู่ใน **Codex Gallery** ด้านล่าง (กรองตามประเภท กด Refresh) ใต้ภาพบอกว่า engine ไหนวาด

## 2. 🎬 วิดีโอ

**ที่ไหน:** 🏴 Miss Goldenweek แถบขั้นตอนบนการ์ดบอกว่าอยู่ขั้นไหน ① Intent ② Brief ③ Style ④ Plan (free) ⑤ Render (paid) ⑥ Review

1. **Intent** ชิปขวาบน **🖼 Image** · **🎬 Series ×10** · **🎞 One clip** เลือกแล้วแถว engine ด้านล่างเปลี่ยนเป็นตระกูลนั้น ระบบจำที่เลือก
2. **Brief** 4 ช่อง 📄 Context · 🎯 Goal · 📚 Source · ⭐ Expectations (พิมพ์ไทยได้) รวมเป็น prompt เดียว **⇄ Free text** สลับเป็นช่องเดียว
3. **Style** เลือก 1 ชิป (สไตล์เภสัชก่อน **Easy to see** สำหรับผู้สูงอายุ ส่วน One Piece 6 แบบซ่อนอยู่หลังชิป **🏴‍☠️ One Piece**) ข้อความสไตล์ถูกต่อท้ายทุก prompt พร้อมบรรทัด 🛡️ Always added (ตัวละครต้นฉบับ ไม่มีโลโก้) ระบบจำสไตล์ที่เลือก
4. **Plan** (free) แถบล่างซ้ายคือโมเดล text (แท็บโลโก้เลือกเจ้า ชิปเลือกรุ่น) กด **Plan 10 episodes** (หรือ **Plan 1 clip**) ได้การ์ด **Episodes**: ชื่อ EN/TH, วัตถุประสงค์, key fact, บทพูด 1 ประโยค, ภาพ 1 ภาพ, คำบรรยายไทย กด ✏️ แก้ในแถว
5. **Render** (paid) เลือกชิป engine (ราคาต่อคลิป 8 s อยู่ใต้ชื่อ) **Clip 9:16** Gemini Omni Flash ≈ $0.80 · **Veo Lite** ≈ $0.40 · **Kling** ≈ $1.01 · **HeyGen** ≈ $0.40 (คนนำเสนอ) · **Seedance** ≈ $0.73 จากนั้น
   - **▶** ที่ตอนเดียว → แถวนั้นถามราคา **≈ $ · 8 s → Render** ยืนยันแล้วเรนเดอร์คลิป 9:16 720p มีเสียง
   - **☑** หลายตอน → แถบล่างบอกจำนวนและราคารวม **▶ Render n · one at a time** ยืนยันครั้งเดียว เรนเดอร์ทีละคลิป กด **⏹ Stop after this one** เพื่อหยุด
   - ทุกคลิปที่เสร็จบันทึกเอง MP4 ไป Storage `teach-clips/{series}/EPnn.mp4` + เอกสาร `clip_series` แล้วขึ้นใน **Codex Gallery → 🎬 Clips** อัปโหลดล้ม → **💾 Save all (n)** ในแถบ
6. **Review** คลิปเล่นในการ์ดพร้อม EP โมเดล เวลาเรนเดอร์ ราคา **⬇ Download** MP4 (720×1280) · **CC ไทย / 🔊 เสียงไทย** (ดูหัวข้อ 3) · **🗑** ลบถาวร (ถามก่อน ตอนกลับเป็น planned)

> จ่ายเฉพาะคลิปที่กลับมา ไม่มี "เรนเดอร์ทั้งหมด" แบบไม่ยืนยัน · เสียงพูดไทยจาก engine ยังไม่นิ่ง ทำเสียงไทยตามหัวข้อ 3

## 3. 🗣️ คลิปไทย

**ที่ไหน:** 🏴 Miss Goldenweek → การ์ด **Episodes** หลังวางแผน และ **Codex Gallery → 🎬 Clips → ▶**

เสียงพูดไทยจาก engine วิดีโอยังไม่น่าเชื่อถือ ทางที่ใช้จริงคือ engine วาดภาพอย่างเดียว แล้วแอปซ้อนซับไทยกับเสียงไทยจาก Gemini TTS ทับลงไป (เสียงเดิมของคลิปถูกปิด)

1. **Plan** ให้ทุกตอนมี **คำบรรยายไทย** 1 บรรทัด ในการ์ด Episodes กด ✏️ แก้ให้เป็นประโยคที่อยากให้พูด ตัวนับใต้ช่องบอกว่าเสียงยาว ≈ กี่วินาทีเทียบกับคลิป ถ้าบอกว่ายาวเกินแม้เร่ง ×1.35 ให้ตัดสั้นลง
2. ช่อง **คำอ่านชื่อยา (เฉพาะเสียง)** ใส่ `Warfarin=วอร์ฟาริน, INR=ไอเอ็นอาร์` คั่นด้วยจุลภาค ใช้ตอนสร้างเสียงเท่านั้น ซับยังสะกดเดิม
3. **▶ Render** ด้วย engine ไหนก็ได้ (Veo Lite ถูกสุด ≈ $0.40) ใน Expectations เขียน "no on-screen text, no speech" ภาพจะได้ไม่ชนกับซับและเสียงไทย
4. ในการ์ดคลิป (หรือ ▶ ใน gallery): **CC ไทย** เปิด/ปิดแถบซับ · **🔊 เสียงไทย** สร้างเสียง Gemini TTS แล้วเล่นพร้อมคลิป (คลิปถูกปิดเสียง) บรรทัดสถานะบอกความยาวเสียงและอัตราเร่ง · ชิป **Kore / Charon / Achird** เลือกน้ำเสียง (เล่าเรื่อง / สงบ / เป็นกันเอง) ระบบจำที่เลือกไว้
5. **⬇ MP4 + ซับ + 🔊** บันทึก MP4 แนวตั้งที่ฝังซับและเสียงไทยแล้ว (ถ้าไม่เปิด 🔊 ปุ่มเป็น **⬇ MP4 + ซับ**) ชื่อไฟล์ `EPnn-th-voice.mp4`

> TTS คิดต่อตัวอักษร ไม่กี่สตางค์ต่อคลิป เสียงถูกเก็บไว้ต่อเสียง×ข้อความ สลับชิปแล้วไม่จ่ายซ้ำ ฟังเทียบ 3 เสียงกับประโยคจริง 1 ประโยคก่อนทำทั้งซีรีส์

## 4. 🐳 เสียง

**ที่ไหน:** 🐳 Laboon สตูดิโอพอดแคสต์/เสียงพูด ("Brook, Soul King")

1. **Step 1 · Transcript** วางหรือพิมพ์สคริปต์ในช่องใหญ่ **Polish** ให้ AI เกลาตามตัวเลือกใต้ปุ่ม: Target Length, Script Format (พูดคนเดียว/บทสนทนา), Podcast Style, Summary Level ข้าง ๆ มีเทมเพลตบทสนทนาและตัวช่วยออกเสียง (CMU phoneme สำหรับคำอังกฤษยาก)
2. **Config (แถบขวา)** 1. Model Selection (backend TTS และรุ่นเสียง) 2. Production Language 3. Voice Rendering Mode 4. Performance Direction (น้ำเสียง จังหวะ การเน้น) บนมือถือเป็น drawer
3. **Step 3 · Produce** เลือก Audio Encoding กับ Sample Rate แล้วกด **Generate** เครื่องเล่นเสียงจะขึ้นใต้สคริปต์ **Send to Podcast** ส่งต่อไป flow พอดแคสต์ **Reset** ล้างสตูดิโอ

> TTS คิดเงินต่อตัวอักษรตาม backend สคริปต์ 5 นาทีไม่กี่เซนต์ เสียงไทยใช้ได้ทั้ง Cloud TTS และ Gemini TTS ลองประโยคสั้น ๆ ก่อน

## 5. 🧭 Log Pose

**ที่ไหน:** 🧭 Log Pose แชตกับโมเดลวิจัยบนฐานความรู้

- พิมพ์คำถามใน **Query Brain** (สูตร Context + Goal + Source + Expectations เหมือนกัน) แล้วส่ง **Suggest Prompts** ให้ตัวอย่างคำถาม
- 📎 **Attach Image for Vision Analysis** แนบรูปไปกับคำถาม (สไลด์ ฉลาก กราฟ)
- **Focus on KB Only** ในแถบข้างให้ตอบจากเอกสารที่อัปโหลดเท่านั้น **Manage Documents** เพิ่ม/ลบเอกสาร
- **Clear Chat** เริ่มใหม่ ส่วนนี้ไม่เขียนฐานข้อมูล เป็นกระดาษทดสำหรับเตรียมภาพ คลิป และสคริปต์ด้านบน
