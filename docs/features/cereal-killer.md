# 🥣 Cereal Killer

A turn-based deduction game for 2–3 interns (Killer vs Detective, plus Lola the police dog), built in phases — plan and board transcription in [`docs/CEREAL-KILLER-PLAN.md`](../CEREAL-KILLER-PLAN.md).

**Built so far: Phase 0 (board + engine), Phase 1 PR 1 (pass-and-play game on one phone, V101.327) PR 2 (the animated tutorial + first-turn coach marks, V101.329) and PR 3 polish (V101.330: Thai first with a small English line, labelled ask chips, one-line chip rails, ✕ / ↺ fixed, lean hand-off).** Phase 1½ (V101.331): play against the bot — `public/cereal-bot.js` (pure brain) wired into the lobby (owner pick C: two cards 🔪 vs 🤖 / 🕵️ vs 🤖 with 🥄 levels).

## How to get to it (user POV)

**Online (V101.335, owner pick B + C):** the lobby has two tabs, 📱 เครื่องนี้ | 🌐 ออนไลน์ (badge = online games waiting for my move). 🌐 lists my online games (ตาคุณ first, then ⏳ รอ …, 👥 รอเพื่อน, 🏁) and two big buttons: ＋ สร้างห้อง (pick 🔪/🕵️ + map → the room screen: a 6-letter code, 📋 copy, two seats, ✕ ยกเลิกห้อง) and 🔑 มีรหัสห้อง (type the code → the game starts for both at once). Every move goes through `cerealAct`; while the other player moves the page shows the public board and "⏳ ตา Pond · n นาที", updating itself; after 1 hour ⏳ เคลม appears. The killer's notebook comes from `cerealAct` `mySecret`. 🏳️ ยอมแพ้ while waiting. Share cards / LINE invite = PR 3.

Phones: 🥣 Cereal in the games row under History (V101.368; was Schedule ▸ beside `💰`) — on a PC-wide window the 🥣 circle left of 📅 in the header instead (V101.334) ▸ lobby: map side A/B, two names, ▸ Start. The phone goes to the killer first; every turn ends on a tint hand-off screen ("Pass the phone to …") that shows only public state, and the next player taps through. Killer: tap a house (home, day 1 only), tap 3 cells, pick 🥣 house + 🌳 witness park chips, 🔒 Lock. Detective: tap a café (day 1), tap cells (dots = legal), ask one card when on / next to 👁️, 🛡️ arrest = tap own / neighbour cell then the red confirm, ▸ End turn. Game over opens the reveal (day rail, the killer's notebook). My games list resumes or replays; 🆕 swaps roles. **Tutorial:** the first 🥣 on a device opens *How to play* — 8 scenes on a demo board that animates by itself (Thai first, small English line, ถัดไป / ‹ / ข้าม, ▶ auto = every 6 s, remembered); `?` in the lobby replays it. On the first real turns a violet coach card with a pulsing ring follows the step (home → 3 cells → 🥣 👁️ chips → 🔒 · café → move → ask → 🛡️ / ▸ End), each once; `ข้ามคำใบ้` stops them for good. Flags: localStorage `cerealTourSeen`, `cerealCoachSeen`, `cerealTourAuto`. State: localStorage `cereal_v1_<userId>` — the killer's path is in there (trust-based until Phase 2). **vs 🤖:** lobby ▸ 🤖 บอท ▸ tap a card (🔪 vs 🤖 = you hide · 🕵️ vs 🤖 = you hunt) and a 🥄 level ▸ เริ่ม. No hand-off screen; the bot's seat shows "🤖 …กำลังคิด" (0.7 s), then one line of what it did in public (cereal · witness · its walk · its card → answer · arrest) and ▸ ตาคุณ. The game keeps `bot: { seat, level }` and `pubDays` (each day's blocked cell, cereal, witness, answers, missed arrests) — the only facts the bot detective reads.

**🏆 / 🏅 (V101.350, Phase 4, owner pick B, mockup-cereal-stats/):** online games only. The 🌐 list starts with two chips, `🏆 n ชนะ` (hidden before a first online game) and `🏅 k/10 ›`; either opens the wins per role (`🔪 · 🕵️ · 🐕`) and a 2-column grid of the ten achievements (earned in colour, the rest grey, each with its seat and how). The reveal shows one `🏅 ได้ใหม่ · …` line under the winner card for the seats that earned one. Ten (Claude's draft, owner "Use these 10", not the printed rulebook): 🕵️ 🧠 สัญชาตญาณ first-try arrest · 🤨 ไม่ไว้ใจ win on the last 🛡️ · 🧱 จนมุม cornered · ⚡ ปิดคดีไว by day 3 · 🙈 ไม่ถามเลย no card; 🐕 K9 bite; 🔪 🗓 วางแผน used the skip day · 🥣 ครบชาม 6 victims · 🫥 ล่องหน survived with no arrest tried · 👃 ไร้กลิ่น won a 3-player game. A resign or ⏳ timeout counts as played / won but earns none. `cerealAct` puts `result.ach` on the game and writes `cereal_stats/{LINE uid}` `{ played, winsKiller, winsDetective, winsLola, ach }` in its own transaction after the game's; rules: own doc readable, nobody writes.

## What usually lies

- `#cerealModal .ck button { width: auto }` out-ranks a plain `.ck-x { width: 30px }` (one id + two classes + a type beats one id + one class): the ✕ and ↺ were tall thin pills for two releases. Size rules for buttons inside `.ck` need `.ck` in the selector.

- `userId` in index.html is a top-level `let`: `window.userId` is undefined in a module file, so the storage key silently became `cereal_v1_anon` until the harness read localStorage back. Read the bare global.
- A coach card placed below its target covers the row that appears next (the witness row under the kill row, ▸ End turn under 🛡️ arrest). A hint rings every element of its step (`#ck-kill, #ck-wit`) and the card goes below the union; Playwright's retry-scroll also exposed a one-frame lag, so the card re-places synchronously on scroll.
- The hand-off screen must be checked by what is NOT in the DOM (no `.ck-cell`, no `.ck-nb`, no path string), not by what is.
- A hand-typed adjacency. The engine derives neighbours from `x,y`; the maps file holds only the per-row letter strings, so compare those to the photo, never a neighbour list.
- "Adjacent" means orthogonal everywhere except Lola's Bark — a test that passes a diagonal arrest or witness is wrong, not the rule.
- The seam between city and suburb is an assumption (plan §7 Q1); `buildMap(…, { seam: false })` exists so the day the printed rules say otherwise is a one-flag change.
