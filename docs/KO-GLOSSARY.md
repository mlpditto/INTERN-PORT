# คำศัพท์เกาหลี — INTERN-PORT (ฉบับร่างสำหรับตรวจ)

คำเกาหลีทุกคำในแอป intern ควรมาจากตารางนี้ เพื่อให้ทั้งแอปใช้คำเดียวกัน
**สถานะ `ร่าง` = ผมเลือกคำมาตรฐานทั่วไป ยังไม่มีเจ้าของภาษาตรวจ** — แก้คอลัมน์ "เกาหลี" แล้วบอกผม ผมจะแก้โค้ดตาม (ทุกคำอยู่ที่เดียวในโค้ด)
ลำดับภาษา: โหมด KR เปิด และ TH ปิด → เกาหลี · เปิด TH ด้วย → ไทยชนะ (ลำดับเดียวกับ `users.preferredLanguage`)
