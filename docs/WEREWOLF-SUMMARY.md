## 1. กติกา (engine · wolf-rules.js)

**บท** (ลำดับในสำรับ): 🐺 หมาป่า · 🔮 ผู้หยั่งรู้ · 🛡️ บอดี้การ์ด · 🧪 แม่มด · 🏹 นักล่า · 💘 กามเทพ · 😈 สมุนรับใช้ · 🃏 คนบ้า · 🧱 ช่างก่ออิฐ · 👤 ชาวบ้าน

| บท | ทำอะไร | ข้อห้าม |
|---|---|---|
| 🐺 | กัด 1 คน/คืน ร่วมกับเพื่อนหมาป่า (เสียงข้างมาก เสมอ = สุ่ม) เห็นเพื่อนกันตั้งแต่ได้การ์ด | กัดหมาป่าไม่ได้ |
| 🔮 | ส่อง 1 คน/คืน ว่าเป็น 🐺 ไหม รู้ผลทันที | ส่องตัวเองไม่ได้ |
| 🛡️ | คุ้มกัน 1 คน/คืน คนถูกกัดที่คุ้มกันรอด | ห้ามคนเดิม 2 คืนติด · ไม่กันพิษ |
| 🧪 | 💚 ชุบคนถูกกัด 1 ครั้ง + ☠️ วางยา 1 ครั้ง ทั้งเกม เห็นว่าใครถูกกัดก่อนตัดสินใจ | 7 คนขึ้นไป · วางยาตัวเองไม่ได้ |
| 🏹 | ตายเมื่อไร (คืนหรือโหวต) ยิง 1 คนทันที | 🎲 เท่านั้น · 6 ที่ขึ้นไป · ถ้าตายแล้วเกมจบพอดี ไม่ได้ยิง |
| 💘 | คืนแรกจับคู่รัก 2 คน (รวมตัวเองได้) คนหนึ่งตายอีกคนตายตาม | 🎲 เท่านั้น · 6 ที่ขึ้นไป · ไม่กด = จับให้สุ่มตอนหมดเวลา |
| 😈 | ฝั่งหมาป่าแต่ไม่ใช่หมาป่า การ์ดบอกชื่อ 🐺 ทุกตัว หมาป่าไม่รู้จักมัน ชนะกับ 🐺 (ตายแล้วก็ชนะ) | 🎲 · 7 ที่ขึ้นไป · ไม่มีปุ่ม · นับเป็น "คนอื่น" ตอนเช็ก 🐺 ≥ ที่เหลือ · 🔮 เห็นว่าไม่ใช่หมาป่า |
| 🃏 | อยู่ฝ่ายตัวเอง ชนะคนเดียวทันทีถ้าถูกโหวตออก | 🎲 · 6 ที่ขึ้นไป · ตายกลางคืน/ถูกยิง/ตายตามคู่รัก = ตายเฉยๆ |
| 🧱 | ชาวบ้าน 2 คนที่รู้จักกัน การ์ดบอกชื่ออีกคน | 🎲 · 7 ที่ขึ้นไป · มาเป็นคู่เสมอ แทน 👤 2 |
| 👤 | ไม่มีพลัง หา 🐺 จากคำพูดแล้วโหวต | – |

**สำรับตามจำนวน** [🐺 🔮 🛡️ 🧪 👤]: 5 = 1·1·1·0·2 · 6 = 2·1·1·0·2 · 7 = 2·1·1·1·2 · 8 = 2·1·1·1·3 · 9 = 3·1·1·1·3 · 10 = 3·1·1·1·4 · บท 🎲 แต่ละบทแทน 👤 1 คน (🧱 คู่แทน 2) ที่นั่ง 👤 หมด = บทท้ายแถวไม่ได้เข้า

**ลำดับกลางคืน** คุ้มกัน → ชุบ → กัด → พิษ · **โหวต** ลับ เปลี่ยนได้ เสียงสูงสุดต้องชนะทั้งคนอื่นและ ⏭ ข้าม ไม่งั้นไม่มีใครออก
**ชนะ** 🃏 ถูกโหวตออก = คนบ้าชนะทันที · 🐺 หมด = ชาวบ้าน · 🐺 ≥ คนที่เหลือ (😈 นับเป็นคนที่เหลือ) = หมาป่า + 😈 · 💘 คู่ต่างฝ่ายเหลือกัน 2 คน = คู่รักชนะ · คู่ฝ่ายเดียวกันชนะกับฝ่ายตัวเอง

## 2. ✈️ บอท Telegram · ฟีเจอร์ที่มี

**ห้องรอ** (`/werewolf` ในกลุ่ม · ห้องละกลุ่ม · คนละ 1 ห้อง)
- `▸ เข้าร่วม` = deep link เปิด DM บอทแล้วกด Start (บอทถึงจะ DM ได้) รายชื่อในห้องอัปเดตเอง · 5–10 ที่นั่ง
- 🏷 **ชื่อในเกม**: พิมพ์ข้อความธรรมดาใน DM หาบอท = เปลี่ยนชื่อ (ก่อนเกมเริ่ม · ห้ามซ้ำในห้อง · 24 ตัว · จำไว้เกมหน้า)
- 🤖 **บอทร่วมเล่น**: `🤖 +1 / −1` + ระดับ `🌆 หัวค่ำ / 🌙 เที่ยงคืน / 🌕 คืนเดือนเพ็ญ` (หัวห้องกด) คน + บอท ≤ 10 ต้องมีคนจริง ≥ 1 · ชื่อ ต้น ใบ ฟ้า นนท์ มุก ภู แพร ก้อง เจ มี 🤖 ต่อท้าย
- 🎲 **บทพิเศษ**: แถวติ๊ก `🏹 💘 😈 🃏 🧱` (หัวห้อง ติ๊กได้หลายบท) + เมื่อติ๊ก ≥ 2 มีชิป `🎲 ใส่ทุกบทที่ติ๊ก / สุ่ม 1 จากที่ติ๊ก` · บรรทัดห้องรอบอกว่าที่นั่งตอนนี้ได้บทไหน (`🎲 🏹 😈 แทน 👤 2 คน · 🧱🧱 ต้อง 7 ที่`) · โชว์ในบรรทัดสำรับตอนเริ่ม
- `▸ เริ่ม` (หัวห้อง ≥ 5) → แจกบททาง DM · `✕ ยกเลิก` ได้ทุกเมื่อ (กลางเกมไม่เฉลยบท)
- `/rules` = กติกาข้อความเดียว

**รอบเกม**
1. 🌙 **คืน** 1:30 — กลุ่มเห็น "คืนที่ n · ⏳" นับถอยหลัง · คนมีบทได้ปุ่มใน DM (กดครั้งเดียว) · 🐺 เห็นเพื่อนเลือกอะไร (บอทเพื่อนบอก "อยากกัด X" + เหตุผลบน 🌕) · 🧪 ได้เมนูหลังหมาป่าเลือกครบ · ครบทุกคน = เช้าทันที
2. ☀️ **เช้า** — "เมื่อคืน 💀 X ตาย" (ไม่บอกบท) + บรรทัดบอทคุย `🤖 ต้น 🤨 Pond · มุก 👍 Mint · ภู 🔮 X ไม่ใช่ 🐺` + 💬 คุย 3:00 (หัวห้องกด 🗳 โหวตเลย ได้) · ⏳ เตือน 1 นาทีครั้งเดียว
3. 🗳 **โหวตลับ** 1:00 — ปุ่มชื่อ + ⏭ ข้าม เปลี่ยนได้ · โชว์แค่ `✅ k/n` · บอทลงทันที · ผล = จำนวนต่อชื่อ ไม่บอกใครโหวตใคร
4. 🏹 ถ้านักล่าตาย → `shot` 0:30 กลุ่มเห็นว่าใครเป็นนักล่า นักล่าเลือกใน DM (บอทยิงทันที)
5. วนจนจบ → ข้อความจบ **เป็นที่เดียวที่เฉลยบททุกคน** (💘 คู่รัก · 🤥 บอทที่หลอก · 💀)

**มารยาท/ความปลอดภัย**: คนตายขอให้เงียบ (ไม่ลบข้อความ) · พลาด 2 รอบติดได้ DM เตือน ไม่เตะ · ข้อความเป็น plain text ชื่อฉีด markup ไม่ได้ · บทอยู่แค่ใน `secret/state` + DM เจ้าตัว · ปุ่มเก่ากดไม่ได้ (มีรอบติดอยู่)

**ระบบ**: `functions/wolf-bot.js` · `exports.wolfBot` (webhook, header `X-Telegram-Bot-Api-Secret-Token`) · `wolfTick` (onSchedule ทุกนาที สำรอง) · `wolfPhase` (เป้า Cloud Tasks, header `X-Wolf-Task-Secret`) · คิว `wolf-phase` us-central1 · secrets `TELEGRAM_WOLF_TOKEN` + `TELEGRAM_WOLF_HOOK_SECRET`
**Deploy** (จากเครื่องนี้ checkout production สะอาด + `npm ci` ใน functions):
```
firebase deploy --only functions:wolfBot,functions:wolfTick,functions:wolfPhase --project intern-port-edfa7
```
