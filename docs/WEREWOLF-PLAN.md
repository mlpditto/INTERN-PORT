## 1. ทำไม Telegram เหมาะกับเกมนี้กว่า LINE

| เรื่อง | LINE OA | Telegram bot |
|---|---|---|
| บอทพูดในกลุ่ม | นับโควตา 300/เดือน **ต่อสมาชิก** → ~9 เกมก็หมด | **ไม่มีโควตารายเดือน** (จำกัดแค่ความเร็ว ~20 ข้อความ/นาที/กลุ่ม) |
| ส่งบทลับให้แต่ละคน | ต้องเปิด LIFF | บอท **DM** หาแต่ละคนได้เลย |
| ปุ่มกดในแชท | Flex + postback | **Inline keyboard** กดแล้วแก้ข้อความเดิมได้ |
| บอทรับข้อความ / ปุ่ม | webhook ของ OA (ใช้กับระบบอื่นอยู่) | **webhook ใหม่** แยกจากของเดิมได้สะอาด |
| หน้าจอสวย ๆ | LIFF | **Mini App** (เปิดหน้าเว็บในแชท) — ทำทีหลังได้ |

เกมทั้งเกมจบในแชท Telegram: ประกาศ / คุย / จับเวลา ในกลุ่ม · บท / กลางคืน / โหวตลับ ใน DM กับบอท

## 2. ของที่มีแล้ว และของที่ต้องเพิ่ม

- มี `functions/telegram.js` = บอทแจ้งเตือน admin (ส่งอย่างเดียว, secret `TELEGRAM_BOT_TOKEN`) — **ไม่ใช้ร่วม**
  เพื่อไม่ให้ห้องแจ้งเตือน admin ปนกับเกม และ token เกมรั่วก็ไม่กระทบระบบแจ้งเตือน
- **ต้องเพิ่ม (เจ้าของทำ):** สร้างบอทใหม่กับ @BotFather (เช่น "Nika Werewolf") → ได้ token →
  ตั้ง secret `TELEGRAM_WOLF_TOKEN` + `TELEGRAM_WOLF_HOOK_SECRET` (ผมไม่แตะ token, repo เป็น public)
- **ต้องเพิ่ม (ผมทำ):** `functions/wolf-bot.js` + `exports.wolfBot` (onRequest webhook) + `exports.wolfTick` (onSchedule ทุก 1 นาที)
- ใช้ซ้ำจาก Cereal: แนวคิดกรรมการในฟังก์ชัน, ข้อมูลลับในเอกสารที่ client อ่านไม่ได้, เครื่องกติกาแบบ pure + node check, achievement อย่างเดียว

## 3. กติกา v1 (Werewolf ทั่วไป · คำและ emoji ของเราเอง)

**5–10 คน** แจกบทตามจำนวน (หัวห้องปรับได้ด้วยปุ่ม):

| คน | 🐺 | 🔮 ผู้หยั่งรู้ | 🛡️ บอดี้การ์ด | 🧪 แม่มด | 👤 ชาวบ้าน |
|---|---|---|---|---|---|
| 5 | 1 | 1 | 1 | – | 2 |
| 6 | 2 | 1 | 1 | – | 2 |
| 7 | 2 | 1 | 1 | 1 | 2 |
| 8 | 2 | 1 | 1 | 1 | 3 |
| 9–10 | 3 | 1 | 1 | 1 | 3–4 |

- **🌙 กลางคืน (⏱ 90 วิ)** — บอท DM ปุ่มให้แต่ละคนตามบท: 🐺 เลือกเหยื่อ (เห็นเพื่อนหมาป่า, เสียงข้างมาก, เสมอ = สุ่ม) ·
  🔮 ส่อง 1 คน → "🐺 / ไม่ใช่" · 🛡️ คุ้มกัน (ห้ามคนเดิม 2 คืนติด) · 🧪 ชุบ 1 + พิษ 1 ต่อเกม · 👤 ได้ "💤 หลับ" (ไม่มีปุ่ม)
  ครบทุกคนก่อนเวลา → เช้าทันที
- **☀️ เช้า** — ลำดับ: คุ้มกัน → ชุบ → กัด → พิษ · บอทประกาศในกลุ่ม "☀️ เช้าวันที่ 2 · 💀 A" (ไม่บอกบท)
- **🗣 กลางวัน (⏱ 3 นาที ปรับ 2/3/5)** — คุยในกลุ่ม · บอทเตือน "⏱ เหลือ 30 วิ"
- **🗳 โหวต (⏱ 60 วิ)** — บอท DM ปุ่มรายชื่อ + "ข้าม" (ลับ) · ประกาศในกลุ่มแค่ **จำนวนเสียง** + ใครออก · เสมอ = ไม่มีใครออก
- **🏁 จบ** — 🐺 หมด = 👤 ชนะ · 🐺 ≥ ที่เหลือ = 🐺 ชนะ · บอทเปิดบททุกคน + บันทึกทุกคืนในกลุ่ม
- **👻 ตายแล้ว** — บอทไม่ส่งปุ่มให้อีก · บอทลบข้อความคนตายในกลุ่มได้ถ้าเจ้าของต้องการ (ต้องให้บอทเป็น admin กลุ่ม, §8)

## 4. การเล่นจริงในแชท

1. ใครก็พิมพ์ `/werewolf` ในกลุ่ม → บอทโพสต์ "🐺 ห้องใหม่ · 0/10 · [▸ เข้าร่วม]"
2. กด **▸ เข้าร่วม** → ลิงก์ `t.me/<bot>?start=<รหัสห้อง>` เปิด DM กับบอท (Telegram ห้ามบอททัก DM คนที่ไม่เคยกด Start,
   ปุ่มนี้แก้ปัญหานั้นในตัว) → บอทตอบ "✅ เข้าห้องแล้ว" และแก้ข้อความในกลุ่มเป็น "3/10 · 👤 A, B, C"
3. หัวห้องกด **▸ เริ่ม** (ครบ 5) → บอท DM การ์ดบทให้ทุกคน
4. วนคืน → เช้า → คุย → โหวต จนจบ · ทุกข้อความของบอทในกลุ่มแก้ข้อความเดิมให้มากที่สุด กันแชทรก

## 5. ระบบ (Firebase เดิม · โครงสร้างแบบ Cereal)

```
wolf_games/{id}        chatId, code, status lobby|night|day|vote|over, host, roles{}, talkSec, round,
                       players{ tgId: { name, alive, seat } }, phaseEnds (ms), msgId (ข้อความหลักในกลุ่ม), log[]
wolf_games/{id}/secret/state   roles{ tgId: role }, picks{}, witch{}, lastGuard   ← client อ่านไม่ได้ (rules: false ทั้งหมด)
wolf_tg/{tgId}         ห้องที่อยู่ตอนนี้ + (ถ้าผูกบัญชี) LINE uid
```

- **ไม่มีหน้าเว็บ client ใน v1** → rules ปิดทั้งหมด (`allow read, write: if false`), มีแต่ฟังก์ชันอ่าน/เขียน
- **webhook `wolfBot`:** ตรวจ header `X-Telegram-Bot-Api-Secret-Token` ทุกครั้ง · รับ `/werewolf`, `/start <code>`, ปุ่ม (callback_query)
  · ทุกการกระทำผ่าน transaction เหมือน cerealAct
- **นาฬิกา `wolfTick`:** onSchedule ทุก 1 นาที หาเกมที่ `phaseEnds ≤ now` แล้วเดินเฟส (จบก่อนเวลาเมื่อทุกคนกดครบ)
  → คลาดได้ ≤ 60 วิ · ถ้าอยากตรงวินาที ใช้ Cloud Tasks (ต้องเปิด API เพิ่ม, §8)
- **ความลับ:** บทอยู่ใน `secret/state` + ส่งผ่าน DM ของคนนั้นเท่านั้น · ทดสอบว่าไม่มีข้อความกลุ่มไหนมีบท/ผลส่อง

## 7. ความเสี่ยง

## 9. เปิดบอทจริง (เจ้าของทำ · เฟส 1–2)

ผมไม่แตะ token เลย ทุกขั้นที่มี token เจ้าของรันเอง

1. Telegram ▸ @BotFather ▸ `/newbot` ▸ ตั้งชื่อ (เช่น Nika Werewolf) ▸ ได้ token
2. ตั้ง secret 2 ตัว (วาง token / พิมพ์รหัสลับยาว ๆ ที่คิดเอง ตอนมันถาม):
   `firebase functions:secrets:set TELEGRAM_WOLF_TOKEN --project intern-port-edfa7`
   `firebase functions:secrets:set TELEGRAM_WOLF_HOOK_SECRET --project intern-port-edfa7`
3. บอกผม → ผม deploy `wolfBot` + `wolfTick` + rules
4. ผูก webhook (PowerShell, อ่าน secret เองไม่แสดงบนจอ):
   `$t = gcloud secrets versions access latest --secret TELEGRAM_WOLF_TOKEN --project intern-port-edfa7`
   `$h = gcloud secrets versions access latest --secret TELEGRAM_WOLF_HOOK_SECRET --project intern-port-edfa7`
   `Invoke-RestMethod "https://api.telegram.org/bot$t/setWebhook" -Method Post -Body @{ url = 'https://us-central1-intern-port-edfa7.cloudfunctions.net/wolfBot'; secret_token = $h; allowed_updates = '["message","callback_query"]' }`
5. เพิ่มบอทเข้ากลุ่ม ▸ พิมพ์ `/werewolf` ▸ เพื่อน 5 คนกด ▸ เข้าร่วม ▸ หัวห้องกด ▸ เริ่ม ▸ ทุกคนได้บททาง DM ▸ เล่นคืน → เช้า → โหวต จนจบ
